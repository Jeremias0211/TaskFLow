# TaskFlow

TaskFlow es una aplicación Android para la gestión y organización de tareas,
inspirada en herramientas como Jira y Trello.

## Versión
Alpha 1.0

## Tecnologías
- Kotlin
- Android Studio
- XML
- Firebase Authentication
- Firebase Firestore

## Funcionalidades actuales
- Registro de usuarios
- Inicio de sesión
- Cierre de sesión
- Dashboard
- Tablero Kanban
- Creación de tareas
- Gestión de hábitos
- Perfil de usuario
- Navegación entre vistas

## Estado del proyecto
Versión Alfa - en desarrollo.

## Instalación
Instalar el archivo APK en un dispositivo Android compatible.
